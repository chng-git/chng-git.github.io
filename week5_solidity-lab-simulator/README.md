## 프로젝트 개요

  - 이 프로젝트는 웹 브라우저 상에서 직접 Solidity 코드를 컴파일하고 배포하는 과정을 체험할 수 있도록 만든 **프론트엔드 시뮬레이터**입니다. Remix IDE의 핵심 경험을 모방하여 제작되었습니다.
  - **Lab 1**에서는 기초적인 Solidity 문법이 네트워크 상에서 어떻게 데이터와 비용으로 치환되는지, 그 메커니즘을 시각적으로 학습할 수 있습니다.
  - **Lab 2**에서는 상태 변수의 누적 변화와 예외 처리(Revert)에 따른 트랜잭션 롤백을 배울 수 있습니다.
  - **Lab 3**에서는 실제 가치(ETH)가 오가는 Faucet(수도꼭지) 컨트랙트를 통해 접근 제어(Access Control)와 시간 조작을 시뮬레이션하며 블록체인의 심화 개념을 마스터할 수 습니다.

## 실습 상세 내용 (Lab 1: Hello World & Variables)

### 탭 1: 가시성(Visibility)과 자동화의 이해 (HelloWorld 기본)

  * **학습 목표:** `public` 상태 변수의 특성 파악
  * **실습 의도:** 상태 변수에 `public` 키워드를 부여했을 때, 이더리움 EVM이 내부적으로 Getter 함수를 자동으로 생성해 준다는 편리함을 시각적으로 체험합니다. (초록색 View 버튼이 자동 생성됨을 확인)

### 탭 2: 캡슐화(Encapsulation)와 가스비(Gas)의 실체 (HelloWorld 확장)

  * **학습 목표:** `private` 변수 제어 및 트랜잭션 비용 이해
  * **실습 의도:** 1. 데이터를 외부로부터 숨기는(`private`) 객체지향적 캡슐화 개념을 도입합니다.
    2\. 데이터를 읽기만 하는 함수(`view`, 가스비 무료)와 데이터를 변경하는 함수(상태 변경, 가스비 소모)를 분리하여 실행해 보며, 블록체인 네트워크에서 \*\*'상태 변경은 곧 비용(ETH 차감)'\*\*이라는 핵심 경제 모델을 깨닫게 합니다.

### 탭 3: 숫자형(Integer) 데이터와 트랜잭션의 이해 (HelloNumber)

  * **학습 목표:** 데이터 타입(`int`) 확장 및 직접 구현(Getter/Setter)
  * **실습 의도:** 1. **트랜잭션의 핵심 데이터:** 앞선 문자열(`string`) 기반 실습에서 벗어나, 실제 블록체인 거래의 핵심인 숫자(`int`)를 다룹니다. 이 숫자는 실제 스마트 컨트랙트에서 송금할 코인의 수량, 투표할 안건의 번호 등을 상징합니다.
    2\. **상태 변경 시뮬레이션:** 특정 숫자(예: 거래 수량이나 선택지)를 입력하고 트랜잭션을 발생시켜 보며, 내가 입력한 데이터가 블록체인 네트워크의 상태(State)를 어떻게 영구적으로 변화시키는지 감각적으로 이해하게 됩니다.
    3\. **도전과제 (보안성 강화):** 중요한 숫자 데이터를 누구나 함부로 바꿀 수 없도록, 개방형(`public`)에서 은닉형(`private`)으로 직접 수정해 보는 미션을 통해 기초적인 보안 설계를 스스로 체득합니다.

## 실습 상세 내용 (Lab 2: Counter & Error Handling)

### 탭 1: 상태의 누적과 가스비 최적화 (Counter)

  * **학습 목표:** 상태 변수 조작에 따른 가스비(Gas) 누적 시각화
  * **실습 의도:** 단순히 숫자를 1씩 올리는 `count()` 함수를 반복 실행하면서, 트랜잭션이 발생할 때마다 네트워크 수수료(가스비)가 어떻게 누적되어 소모되는지 대시보드 차트를 통해 직관적으로 확인합니다. 비효율적인 코드가 블록체인에서 왜 치명적인지 경제적 관점에서 이해합니다.

### 탭 2: 예외 처리와 트랜잭션 롤백 (CheckNumber)

  * **학습 목표:** `revert`를 활용한 에러 핸들링과 상태 롤백(Rollback) 경험
  * **실습 의도:** 입력값에 음수가 들어왔을 때 트랜잭션을 강제로 중단시키는 `revert` 패턴을 테스트합니다. 에러가 발생하면 가스비는 소모되지만 블록체인의 상태는 이전으로 완벽히 되돌아가는 '원자성(Atomicity)'을 시뮬레이션 환경에서 안전하게 실험해 볼 수 있습니다.

<br>

## 실습 상세 내용 (Lab 3: Faucet Master)

### 탭 1: 자산의 입출금 (Basic Faucet)

  * **학습 목표:** `payable` 함수와 컨트랙트 자체 공용 잔액(`address(this).balance`) 이해
  * **실습 의도:** 일반적인 데이터가 아닌 '이더(ETH)'라는 가치를 컨트랙트에 입금(`deposit`)하고 출금(`withdraw`)하는 과정을 구현합니다. 개인 지갑의 잔액과 스마트 컨트랙트 공용 금고의 잔액이 서로 어떻게 교환되고 분리 관리되는지 거대 전광판을 통해 실시간으로 확인합니다.

### 탭 2: 시간 제약과 쿨타임 (Time Faucet)

  * **학습 목표:** `block.timestamp`와 `mapping`을 활용한 레이트 리밋(Rate Limit) 제어
  * **실습 의도:** 한 번 자원을 받아 간 유저가 24시간 동안 다시 출금하지 못하도록 막는 로직을 검증합니다. 실제 테스트넷에서는 확인하기 까다로운 시간 제약 코드를 시뮬레이터에 내장된 **'24시간 빨리 감기(Time Skip)'** 버튼을 이용해 즉각적으로 통과시키며 테스트하는 강력한 경험을 제공합니다.

### 탭 3: 권한 증명과 보안 (Owner Faucet)

  * **학습 목표:** `msg.sender`를 이용한 중앙 집중형 접근 제어(Access Control) 패턴 체득
  * **실습 의도:** 컨트랙트를 최초 배포한 '관리자(Owner)'와 일반 유저의 자아를 UI 드롭다운으로 전환해 가며 테스트합니다. 오직 관리자 계정으로 접속했을 때만 공용 금고의 전체 자산을 회수(`withdrawAll`)할 수 있는, 블록체인 실무의 핵심 보안망을 직접 공격해 보고 방어해 봅니다.

## 주요 기술 및 아키텍처 특징

  * **Multi-Page Application (MPA) 렌더링 로비:** 각 실습(Lab)을 독립된 HTML 파일로 분리하여 코드 꼬임 현상을 원천 차단했으며, 메인 `index.html` 로비를 통해 각 포탈로 매끄럽게 이동하고 로컬 스토리지 기반의 '통합 학습 진행률'을 공유합니다.
  * **Virtual EVM & Time Engine:** 브라우저 환경에서 작동하는 자바스크립트 가상 머신 로직을 통해 실제 네트워크 연결 없이도 트랜잭션 수수료, 지갑 잔액, 블록 생성 시간을 완벽하게 시뮬레이션합니다.
  * **Real-time Interaction:** 코드 컴파일 결과와 변수 값이 즉시 UI 대시보드와 버튼에 반영되어 학습 피드백 루프가 매우 짧고 직관적입니다.
  * **통합 단축키 시스템:** 런처 이동, 컴파일, 배포 등을 단축키(`Ctrl+Enter` 등)로 지원하여 실제 IDE를 다루는 듯한 쾌적한 개발 경험을 제공합니다.

## 주의사항

  * 본 도구는 교육 및 학습용 시뮬레이터로, 실제 메인넷의 가스비 계산 모델이나 블록 생성 딜레이와는 미세한 차이가 있을 수 있습니다.
  * 브라우저 로컬 스토리지에 코드가 임시 저장되지만, 강력한 새로고침이나 캐시 삭제 시 배포된 네트워크 상태는 초기화됩니다.

01

기획 배경 및 문제 정의

블록체인의 고립성

Oracle Problem

블록체인 네트워크의 결정론적(Deterministic) 구조로 인한 인터넷 외부 데이터(OpenWeatherMap API 등) 직접 호출 불가 한계

외부 데이터 조작 리스크

Data Feed Risk

오프체인 데이터 피드 오염 및 전송 과정 해킹 리스크
• 악의적으로 조작된 데이터 주입 시 스마트 컨트랙트 오작동 및 대규모 자산 탈취로 직결

프로젝트의 출발점 (Motivation)

단순 토큰 전송 반복 메커니즘 탈피
• 직전 학기 블록체인 기본 이론(투명성/무결성)과 이번 학기 스마트 컨트랙트 상태 제어 실습 로직의 유기적 결합
• 실생활 환경 조건에서 안전하게 구동되는 조건부 자산 관리 서비스 흐름 구축

02

프로젝트 핵심 목표

AI 기반의 교차 검증 도입

무검증 외부 데이터 주입 방식 탈피
• AI 에이전트를 가교로 활용한 데이터 안정성 및 무결성 사전 필터링 검증 레이어 추가

핵심 메커니즘: 데이터 과거 패턴 분석 및 이상치 탐지 연산 수행 후, 오염 징후가 없는 정상 데이터셋만 선택적으로 온체인 반영

확장된 서비스 흐름 구현

고정된 토큰 전송 흐름의 확장
• 실시간 기상 데이터 등 외부 동적 환경 변수 변화에 유기적으로 연동되는 조건부 파이낸셜 서비스 설계

동적 리워드 구조: 실시간 강수량, 기온 등 기상 지표 임계치가 예치 자산 보상률(Yield Rate) 산정 공식에 직접 반영되는 구조

03

사용 기술 스택

분류 (Layer) 기술 및 도구 (Tech Stack) 상세 역할 (Responsibility)
Blockchain Solidity (0.8.20+) OpenZeppelin Sepolia Testnet MetaMask Hardhat • 조건부 토큰 예치 및 보상 공식 Vault 컨트랙트 로직 설계
• 가이드라인에 따른 OpenZeppelin 시큐어 표준 플러그인 적용
• 테스트넷 스마트 계약 배포 및 트랜잭션 가스 비용 검증
• 로컬 하드햇 가상 노드 환경을 이용한 익스플로잇 시뮬레이션
AI & Integration Gemini 3.1 Pro Node.js Python • 호출된 외부 원본 데이터의 구조적 무결성 분석 및 이상치 탐지
• 대형 언어 모델 지능 기반의 데이터 오염 스캐닝 및 서명 제어
• 오프체인 가교 역할을 담당할 전용 MCP 서버 아키텍처 구축 및 가공
External Data OpenWeatherMap API • 실시간 기상 상태 정보 지표(강수량, 기온) 실시간 동적 공급
• 외부 시뮬레이션용 데이터 소스 게이트웨이 파이프라인 연동
04

구현 절차 — Phase 1

01

자산 예치 서비스 배포 단계

On-chain Development

사용자 토큰 자산(LAB/BCT) 예치(Stake) 및 회수용 코어 금고 스마트 계약 구축 및 Sepolia 테스트넷 배포

외부 기상 조건 변동에 따라 보상 이율 및 지급 수율이 유동적으로 변하는 WeatherSecureVault 아키텍처 구현

02

오프체인 데이터 통신 게이트웨이 구축

Off-chain Integration

안정적 데이터 수집 목적의 Node.js/Python 기반 전용 MCP 서버 인프라 구축

OpenWeatherMap API 주기적 자동 호출 및 기상 지표(기온, 강수량) 데이터 1차 전처리 가공

05

구현 절차 — Phase 2

03

AI 지능형 보안 감사 및 실시간 트랙킹

AI Verification

1차 정제된 오프체인 기상 데이터를 Gemini 3.1 Pro AI 레이어에 실시간 바이패스 주입

AI 모델의 데이터 과거 패턴 교차 검증 분석 진행
• 이상 징후 및 변조가 없는 무결성 확정 시 온체인 핵심 함수(updateWeatherState) 트랜잭션 트리거

04

조건부 토큰 전송 및 상태 제어 실행

On-chain Execution

검증 완료된 날씨 수치 지표(임계치 이상의 폭우/폭설 강수량 등) 기반 스마트 계약 로직 자동 자율 구동

예치 유저 대상 추가 인센티브 리워드 토큰 계산 및 분배 발행
• 데이터 비상 탐지 시 출금 락업(Lock) 제한 등 실시간 자산 흐름 제어 제동

# Week 1 Assignment

## 프로젝트 개요
- GitHub 계정을 생성하여 정적 웹 페이지를 구축하고, 외부 API를 연동하여 암호화폐(Bitcoin, Ethereum)의 시세를 실시간으로 대시보드에 시각화합니다

## 실습 상세 내용
### 1. 정적 시세 데이터 기록 (`bitcoin-ethereum-prices.md`)
* 특정 시점(2026-03-03)의 주요 코인 시세를 마크다운 테이블 형식으로 기록하여 데이터 아카이빙 기초를 다졌습니다.
* 코인 이름, 심볼, 가격(USD), 업데이트 날짜를 명확히 구분하여 가독성을 확보했습니다.

### 2. 실시간 시세 대시보드 구현 (`index.html`)
* **API 연동:** `fetch` 비동기 통신을 사용하여 CoinGecko API로부터 최신 가격 데이터를 가져옵니다.
* **UI/UX 디자인:** * `Apple SD Gothic Neo` 폰트와 부드러운 카드 스타일 UI를 적용했습니다.
    * 데이터 로딩 중에는 '연결 중...' 메시지를 표시하여 사용자 피드백을 강화했습니다.
* **상태 모니터링:** '마지막 성공 시각'을 하단에 표기하여 데이터의 신뢰성을 실시간으로 확인할 수 있게 구현했습니다.

## 기술적 최적화

### 1. API 호출 안정성 및 효율화
* **Rate Limit 대응:** 무료 API의 호출 제한 정책을 고려하여 업데이트 주기를 **2분(120,000ms)**으로 최적화했습니다. 불필요한 서버 부하를 줄이면서도 최신 정보를 유지합니다.
* **캐시 방지 로직:** API 요청 URL 뒤에 타임스탬프(`Date.now()`)를 쿼리 파라미터로 추가하여, 브라우저 캐시로 인해 과거 데이터가 표시되는 현상을 방지했습니다.

### 2. 예외 처리 및 네트워크 대응
* **에러 핸들링:** `try-catch` 구문을 통해 API 응답 실패나 네트워크 단절 시에도 전체 페이지가 멈추지 않도록 설계했습니다.
* **사용자 알림:** 장애 발생 시 하단 상태 박스에 빨간색 경고 문구(⚠️ 서버 연결 불안정)를 노출하여 사용자가 상황을 인지할 수 있도록 처리했습니다.

Upbit MCP Console

업비트 실시간 데이터 조회 통제실.

기말 프로젝트 시연용 UI입니다. 버튼을 누르면 웹 백엔드가 MCP Client로 동작하여, Upbit MCP Server에 구현된 전용 도구(Tool)들을 호출하고 그 결과를 반환합니다.

실제 MCP stdio 연결 Upbit Public API 기말 프로젝트 시연용

1
브라우저 UI마켓 코드 입력 후 기능 실행
2
Web Backend요청을 받아 MCP client 세션 생성
3
Upbit MCP Server도구(Tool) 실행 및 데이터 수집
4
External API업비트 거래소 실시간 데이터 연동
5
Tool Result정제된 데이터를 UI에 즉시 표시
